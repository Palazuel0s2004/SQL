# 🗄️ Proyectos y Prácticas de Bases de Datos (SQL)

Este repositorio almacena mis scripts y modelos relacionales enfocados en la administración, estructuración y consultas de bases de datos. Como parte de mi formación en Ingeniería Informática, utilizo este espacio para documentar mis prácticas con comandos avanzados, uniones (JOINs), subconsultas y diseño de esquemas, utilizando principalmente PostgreSQL y MySQL.

## 📂 Estructura del Repositorio

El repositorio contiene los siguientes proyectos y casos de estudio:

| Archivo / Directorio | Descripción |
| :--- | :--- |
| `Trabajo_Final_BDS_1` | **Trabajo Final.** Proyecto integrador correspondiente a la materia de Base de Datos 1, consolidando los conceptos fundamentales de diseño y consultas. |
| `Caso_POS_sql` | **Caso de Estudio POS.** Modelado y scripts de prueba para un sistema de Punto de Venta (Point of Sale), abarcando transacciones e inventario. |
| `Simulacion_Comercio_DB` | **Simulación Comercial.** Diseño de una base de datos estructurada para simular operaciones, ventas y gestión de un entorno comercial. |

## 🛠️ Tecnologías y Herramientas
* **Lenguaje:** SQL
* **Motores de Bases de Datos:** PostgreSQL y MySQL
* **Conceptos Aplicados:** Creación de tablas (DDL), manipulación de datos (DML), consultas complejas, administración de bases de datos relacionales.
